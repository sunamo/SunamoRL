# SunamoRL

## Short description

Balíček Sunamo pro načítání zdrojů a lokalizaci: třída RL s jazykem aplikace, IResourceHelper, ResourceLoaderRL a AttributesHelper. Obsahuje sdílená rozhraní a enumy a vygenerované konstanty XlfKeys. Slouží jako podpora lokalizace v appkách Sunamo.
